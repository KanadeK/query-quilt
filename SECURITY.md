# Security policy

## Supported versions

Security fixes target the latest tagged release.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting feature for this repository. Do not open a
public issue for unpatched vulnerabilities.

## Data boundary

Query Quilt executes local analysis inside the browser. It does not upload imported data.
Exported files are created only after an explicit user action. See
[docs/PRIVACY_AND_SECURITY.md](docs/PRIVACY_AND_SECURITY.md).
